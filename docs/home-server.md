# 집 PC 서버

## 예정 구성

가족 앱 → HTTPS / Cloudflare Tunnel → `127.0.0.1:8080` Spring Boot

지금은 로컬 API만 준비한 상태입니다. Tunnel, 도메인, 가족 로그인, 사진 저장·조회, DB 및 게임 규칙은 아직 설정하지 않았습니다. 서버는 기본적으로 PC의 루프백 주소에만 바인딩되며, 공유기·방화벽 설정은 변경하지 않습니다.

## 네트워크와 인증

- Cloudflare Tunnel을 같은 PC에 실행하면 공유기 포트포워딩 없이 로컬 API에 연결할 수 있습니다.
- Tunnel이 연결됐다는 사실만으로 가족 전용 접근이 되는 것은 아닙니다. 서버가 다섯 명의 계정을 확인하고 요청별 접근을 검증해야 합니다.
- 현재 공개 가능한 응답은 민감 정보가 없는 `/api/v1/health` 및 `/actuator/health`뿐입니다. 나머지 경로는 차단됩니다.
- Android 디버그 빌드만 에뮬레이터·USB 로컬 주소에 HTTP를 허용합니다. 배포용 서버 주소는 HTTPS로 제한합니다.

## 사진

사진 원본은 Git 저장소 밖 또는 Git에서 제외한 `data/photos/`에 저장할 예정입니다. 업로드 크기 제한 초안은 파일당 10MB, 요청당 30MB입니다. 실제 업로드 API 및 이미지 검증은 후속 구현이 필요합니다.

Cloudflare Tunnel에는 사진 몇 장까지 허용한다는 수치가 없습니다. 공개 Tunnel에 적용되는 CDN의 이미지·대용량 파일 조건을 고려해야 합니다. 압축만 하면 어떤 사용량도 허용된다고 가정하지 않습니다. 필요해지면 사진 전송을 R2 등으로 옮길 수 있도록 저장소 인터페이스를 분리할 예정입니다.

## 실행 환경 변수

| 이름 | 기본값 | 용도 |
| --- | --- | --- |
| `MOA_SERVER_ADDRESS` | `127.0.0.1` | 서버 바인딩 주소 |
| `MOA_SERVER_PORT` | `8080` | 서버 포트 |

전역 환경 변수 대신 서버 실행 프로세스에만 지정하세요. `.env` 파일은 현재 서버가 자동으로 읽지 않습니다.

## 운영 전 준비

가족 인증·DB·사진 API 구현 후 자동 시작, 프로세스 재시작, 절전 설정과 백업을 구성합니다. 현재는 윈도우 서비스를 설치하거나 PC의 절전·방화벽을 변경하지 않았습니다. 사진과 DB는 별도 드라이브에 일관된 상태로 백업하고 복구를 확인해야 합니다.
